# Networking — mandatory questions (stub)

1. How many sites and approximate users per site?
2. What is the current access and uplink speed (1G / 10G / 25G / 40G / 100G)?
3. Is there an existing core / distribution / access design to retain or replace?
4. Which VLANs / VRFs / security zones must be preserved?
5. What high-availability target (e.g. dual core, dual uplink) is required?
6. Who operates the network day-2 (internal NOC, MSP, mixed)?
