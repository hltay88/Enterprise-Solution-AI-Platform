# Networking Knowledge Pack (stub)

Vendor-neutral guidance for enterprise campus and data-centre networking discovery.

## Typical business problems
- Congested access / uplink capacity
- Flat L2 domains causing broadcast risk
- Incomplete segmentation between users, servers, and OT
- Weak visibility into traffic and change control

## Discovery focus
- Sites, buildings, floors, and user density
- Current switching / routing topology (core / distribution / access)
- Uplink speeds, oversubscription, and redundancy
- IP addressing, VLANs, and routing protocol in use
- Management / monitoring tools already deployed
