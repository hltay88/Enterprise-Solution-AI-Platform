# Wi-Fi (Phase 3 domain stub)

Vendor-neutral Wi-Fi domain guidance for Solution Domain Identification.

## When this domain applies
- Wireless coverage, capacity, SSIDs, or roaming requirements appear in the Published RKM.
- Dependency for collaboration, IoT, or guest access that needs WLAN.

## Typical dependencies
- Campus LAN (wired underlay)
- Identity (802.1X / captive portal)
- Cybersecurity / NAC

## Selection notes
Do not select vendor WLAN products at this stage. Capture open questions for survey, density, and authentication if missing.
