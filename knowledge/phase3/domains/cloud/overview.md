# Cloud (Phase 3 domain stub)

Vendor-neutral cloud domain guidance.

## When this domain applies
- Public, private, or hybrid cloud workloads, landing zones, or cloud connectivity in the RKM.

## Typical dependencies
- Identity, Cybersecurity, Monitoring / Observability
- May depend on Internet or WAN / SD-WAN for connectivity

## Selection notes
Do not assume a hyperscaler. Prefer clarification when cloud provider or residency is unspecified.
