# Cybersecurity (Phase 3 domain stub)

Vendor-neutral security domain guidance.

## When this domain applies
- Explicit security, zero trust, endpoint, SIEM/SOC, or secure edge requirements.

## Typical dependencies
- Identity
- Monitoring / Observability
- May imply ZTNA / VPN or Firewall / Security Edge as related domains

## Selection notes
Customer-named vendors are preferences, not proof of SKU fit. Do not invent controls not supported by the RKM.
