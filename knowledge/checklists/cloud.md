# Cloud (Private / Public / Hybrid) Clarification Pack

Use for public cloud landing zones, private cloud, hybrid connectivity, or multi-cloud programs.

## Strategy
- Which clouds are in scope (Azure/AWS/GCP/private) and why?
- Landing-zone / account-OU strategy and ownership model?
- Workloads to migrate vs cloud-native rebuild?

## Connectivity & identity
- Private connectivity (ExpressRoute/Direct Connect/VPN) requirements?
- Identity federation and privileged access model?
- DNS, IP addressing, and hybrid name resolution?

## Governance
- Cost controls, tagging, and FinOps ownership?
- Security baseline (CIS, landing zone policies) to enforce?
- Data residency and sovereignty constraints?

## Operations
- Who runs cloud day-2 (customer cloud team, MSP, vendor)?
- Observability stack expectations?
- Exit / portability requirements?
