# Servers / Compute Clarification Pack

Use for rack/blade/server refresh, compute expansion, or bare-metal estate projects.

## Estate & workloads
- Current server inventory (count, age, CPU/RAM/storage profile) and what is being replaced?
- Workloads per host class (apps, DB, VDI, analytics) and consolidation ratio targets?
- Virtualization vs bare-metal split?

## Hardware specs
- Form factor preferences (rack/blade/tower) and rack U / depth limits?
- CPU generation, core count, RAM, local disk/boot media expectations?
- GPU, HBA, NIC, or TPM/secure-boot requirements?

## Lifecycle
- Warranty / support level (e.g. 3/5/7 year) and onsite response needs?
- Imaging / provisioning toolchain (PXE, SCCM, Ansible, etc.)?
- Migration approach for workloads from old hosts?

## Facilities
- Power (PSU redundancy), cooling, and rail/cable management constraints?
- Out-of-band management network readiness (iLO/iDRAC/IPMI)?
