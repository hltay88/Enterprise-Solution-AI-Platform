# Microsoft Platform Clarification Pack

Use when the opportunity is Microsoft-centric (Entra ID, Azure, M365, Windows, Defender, SQL on Microsoft stack).

## Tenancy & identity
- Existing Microsoft tenant(s) and who is Global Admin owner?
- Hybrid identity model (cloud-only vs Entra Connect) and MFA gaps?
- Device join model (Entra join / hybrid join) targets?

## Workloads
- Which Microsoft clouds/workloads are in scope (Azure, M365, Defender, Intune, Power Platform)?
- Licensing SKUs already owned vs net-new?
- Sovereignty / data residency constraints for Microsoft regions?

## Security baseline
- Defender / Intune / Conditional Access baseline expected at go-live?
- Privileged Identity Management requirements?
- Landing zone / Azure Policy expectations if Azure IaaS/PaaS is included?
