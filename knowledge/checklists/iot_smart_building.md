# IoT / Smart Building Clarification Pack

Use for building IoT, BMS integration, energy monitoring, sensors, or smart-workplace programs.

## Outcomes
- Which KPIs matter (energy, comfort, space utilization, safety)?
- Buildings/floors in phase-1 scope?
- Integration with existing BMS/HVAC/lighting?

## Architecture
- Sensor types and density expectations?
- Edge gateways vs cloud IoT platform preference?
- OT/IT network segmentation and security baseline?

## Data & ops
- Dashboards, alerts, and who acts on them?
- Data ownership / retention / privacy constraints?
- Facilities vs IT operating model?
