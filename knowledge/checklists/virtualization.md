# Virtualization Clarification Pack

Use for hypervisor refresh, VM consolidation, VDI, or virtualization platform migration.

## Platform
- Current hypervisor and target platform constraints?
- Cluster size, HA/DRS policies, and resource pools?
- Licensing model to preserve or change?

## Workloads
- VM count, average/peak CPU-RAM, and noisy-neighbor concerns?
- VDI / published-apps user concurrency if applicable?
- Nested dependencies (appliances, GPU VMs, RT apps)?

## Operations
- Image templates, IaC, and change-control expectations?
- Backup/replication tooling already in place?
- Skills gap / training for the target platform?
