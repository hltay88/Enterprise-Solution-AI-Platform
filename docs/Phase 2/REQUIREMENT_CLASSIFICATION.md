# REQUIREMENT_CLASSIFICATION.md

Every requirement shall belong to exactly one primary classification.

---

## Business
Examples: Increase productivity, Reduce downtime, Improve customer satisfaction, Reduce operational cost, Expand business, Improve security

## Functional
Examples: Support VPN, Support VLAN, Support IPv6, Support Multi-Site, Support WiFi 7, Support Cloud Backup

## Non-Functional
Availability, Performance, Scalability, Maintainability, Reliability, Security, Latency, Compliance, Logging, Monitoring, Observability

## Infrastructure
Network, Wireless, Servers, Storage, Virtualization, Backup, Data Centre, Cloud

## Security
Firewall, ZTNA, EDR, SIEM, Identity, MFA, Email Security, DLP

## Collaboration
Microsoft Teams, Zoom, VoIP, Meeting Rooms

## Audio Visual
LED Video Wall, Digital Signage, Interactive Display, Projector, Control Room, PA System

## Smart Building
IoT, Access Control, CCTV, Visitor Management, Energy, Building Management

---

## Priority Levels
Critical / High / Medium / Low

## Requirement Status
Draft → Validated → Approved → Implemented → Verified → Retired
