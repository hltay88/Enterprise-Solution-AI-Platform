# Phase 5 Architecture Decisions

ADR-032 — Enterprise knowledge is a governed domain object.

ADR-033 — Only authorized published knowledge is eligible for normal production retrieval.

ADR-034 — Retrieval is tenant- and permission-aware.

ADR-035 — AI providers are behind provider-neutral interfaces.

ADR-036 — Agent outputs are structured, traceable and reviewable.

ADR-037 — The orchestrator owns cross-domain coordination and conflict handling.

ADR-038 — Agents do not approve customer-facing outputs.

ADR-039 — Material AI, knowledge and governance actions are auditable.

ADR-040 — Multi-tenancy is a security boundary, not a UI feature.
