# Presentation Generator

Default storyline:
1. Title
2. Executive Summary
3. Customer Situation
4. Challenges
5. Requirements
6. Proposed Architecture
7. Solution Overview
8. Key Components
9. Technical Highlights
10. Benefits
11. Implementation
12. Timeline
13. Risks/Assumptions
14. Next Steps

Slide object:
- slide_id
- title
- objective
- key_message
- body_content
- visual_type
- visual_data
- source_refs
- speaker_notes
- confidence

Rule: one primary message per slide.
