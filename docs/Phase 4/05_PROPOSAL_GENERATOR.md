# Proposal Generator

Default structure:
1. Cover
2. Executive Summary
3. Customer Understanding
4. Challenges
5. Requirements
6. Proposed Solution
7. Architecture
8. Solution Components
9. Benefits
10. Implementation Approach
11. Timeline
12. Assumptions
13. Risks
14. Exclusions
15. Support/Warranty
16. Next Steps

Rules:
- Use approved source data.
- Technical claims require traceability.
- Missing information becomes an explicit assumption or clarification.
- Pricing is excluded unless authoritative approved data exists.
