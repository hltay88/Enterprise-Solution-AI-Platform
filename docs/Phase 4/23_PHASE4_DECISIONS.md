# Phase 4 Architecture Decisions

ADR-025 — Every generation run uses an immutable source snapshot.

ADR-026 — AI generates structured content; rendering engines create files.

ADR-027 — Customer-facing documents require human approval.

ADR-028 — Templates are versioned independently from documents.

ADR-029 — Proposal, presentation, SOW, design and BOM reference the same approved solution snapshot unless explicitly revised.

ADR-030 — Prices, discounts, warranties, dates and contractual terms require authoritative approved data.

ADR-031 — AI provider integration remains behind an abstraction layer.
