# BOM and Document Package

Package:
- Proposal
- Presentation
- Solution Design
- SOW
- BOM
- Architecture diagrams
- Supporting appendices

BOM rules:
- Use validated BOM data.
- Preserve vendor/model/quantity/source.
- Do not invent pricing.
- Distinguish mandatory, optional and recommended items.
- Flag unresolved compatibility or licensing issues.

All package documents must reference the same project, solution, architecture and BOM versions.
