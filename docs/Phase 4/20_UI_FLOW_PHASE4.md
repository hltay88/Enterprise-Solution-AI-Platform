Screens:
- Document Workspace
- Proposal Editor
- Presentation Outline
- SOW Editor
- Solution Design Editor
- Source/Traceability Panel
- Review Comments
- Approval Panel
- Export Center

Users must understand what Atlas generated, which sources were used, what needs review and what changed.
