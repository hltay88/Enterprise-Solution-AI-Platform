# VERSIONING.md

**Requirement Knowledge Model Version Control**  
**Version:** 1.0

---

## Objective

Every project maintains complete requirement history.

No information is overwritten.

---

## Version Lifecycle

```text
Draft
  ↓
AI Generated
  ↓
Human Review
  ↓
Approved
  ↓
Published
  ↓
Archived
```

---

## Rules

- One Active Version.
- Unlimited Historical Versions.
- Previous versions immutable.
- Approval required.

---

## Version Numbering

```text
1.0 → 1.1 → 1.2 → 2.0
```

- **Major:** Business Requirement Changed
- **Minor:** Clarification Added
- **Patch:** Typographical Correction

---

## Audit Trail

Every change stores:

- Who
- When
- Why
- Previous Value
- New Value
- Approval
- Timestamp

---

## Comparison

Users can compare:

- Requirement Changes
- Business Changes
- Risk Changes
- Assumption Changes
- Scope Changes
- Clarification Changes
- AI Reasoning Changes
