# Solution Architecture Standard

## Architecture layers
1. Business
2. Functional
3. Logical
4. Physical
5. Technology
6. Operations

## Architecture principles
- Requirements traceability
- Vendor neutrality before vendor selection
- Security by design
- Availability appropriate to business criticality
- Scalability
- Operability
- Observability
- Interoperability
- Cost awareness
- Lifecycle awareness

## Architecture output
Every architecture must contain:
- objective
- scope
- requirements addressed
- architecture components
- interfaces
- dependencies
- assumptions
- risks
- alternatives
- rationale
- traceability

## Do not
- Select a product merely because it is popular.
- Treat a vendor name in a requirement as proof that a specific SKU is correct.
- Hide assumptions.
- Present uncertain capacity as fact.
