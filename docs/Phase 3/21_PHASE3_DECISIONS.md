# Phase 3 Architecture Decisions

## ADR-017 — RKM is authoritative
Architecture must consume a published RKM version.

## ADR-018 — Vendor neutrality first
Design capability and architecture before product selection.

## ADR-019 — Evidence traceability
Every architecture component must trace to requirements or documented dependencies.

## ADR-020 — AI recommendations require review
AI cannot approve an architecture.

## ADR-021 — Catalogue data is versioned
Vendor/product information must retain source and date.

## ADR-022 — External BOM is evidence
Imported distributor/vendor BOMs are inputs for validation, not unquestioned truth.

## ADR-023 — Multi-domain support
The platform must support IT and non-IT enterprise solution domains including AV, LED, digital signage and smart building.

## ADR-024 — Provider independence
AI services must be accessed through an abstraction layer so the platform is not locked to one model provider.
